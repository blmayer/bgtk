    Added comprehensive CSS named colors enum and fixed special element coloring

    - Added enum BGTK_Color to bgtk.h with a large set of standard CSS color names (including fuchsia, various shades of blue, red, etc.) as 0xAARRGGBB constants. Makes it easy for users to pick nice colors without hard-coded hex values.
    - Updated draw_text_widget to apply BGTK_COLOR_FUCHSIA (instead of magic number) for headers (level > 0), links (starting with "=> "), and bullet points (starting with •). The level==10 path ensures wrapped continuation lines of links and bullets are also colored.
    - Fixed mock/headless backend color rendering: take_screenshot now converts the internal buffer to proper opaque RGBA for stbi_write_png (previously A=0 on drawn pixels caused special colors like fuchsia to disappear, leaving only grayscale/black text visible in test screenshots).
    - Ensured drawing code writes full alpha (0xFF) on pixels for consistency.
    - Supporting refinements in Gemini browser (both real app and test harness) for parser-level color stamping and spacing.
