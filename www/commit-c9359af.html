    Refactored init/config separation and improved headless/mock testing support

    - Moved default configuration (theme, font size) and platform font
      selection (with #ifdefs) into init_config_defaults() so that
      bgtk_init and bgtk_init_resources only perform loading.
    - bgtk_init_mock is now a complete, standalone implementation.
    - Added bgtk_destroy_mock() and simplified bgtk_destroy() (buffer
      ownership is now handled explicitly by the mock path).
    - Added FT_Select_Charmap(FT_ENCODING_UNICODE), safe unsigned casts
      for character lookup, and post-load glyph validation for more
      robust font handling across platforms.
    - Updated README.md and the header in test/headless.c with
      documentation and examples for testing with mocks (bgtk_init_mock,
      take_screenshot, bgtk_inject_event, bgtk_destroy_mock).
    - Updated test/headless.c to use the new mock init/destroy and
      take_screenshot APIs.
    - Removed dead DEFAULT_FONT_SIZE define and other minor cleanups.
    
    This makes isolated widget development and visual regression testing
    (via PNG snapshots) much more practical without requiring a running
    BGCE server.

+## Testing with Mocks (Headless Mode)
+
+BGTK supports a mock/headless mode so you can develop, debug, and visually inspect UIs **without** a running BGCE server, real display, or input devices.
+
+This is the recommended way to test widgets in isolation:
+
+```c
+struct BGTK_Context *ctx = bgtk_init_mock(600, 400);
+
+// Build your widget tree exactly as you would in a real app
+ctx->root_widget = my_ui_builder(ctx);
+bgtk_draw_widgets(ctx);
+
+// Dump the current rendered state to a PNG you can open in any viewer
+take_screenshot(ctx, "before.png");
+
+// Simulate user input (mouse clicks, keyboard, etc.)

+    .type = EV_KEY,
+    .code = BTN_LEFT,
+    .value = 1,
+    .x = 120,
+    .y = 80,
+};
+bgtk_inject_event(ctx, click);
+
+take_screenshot(ctx, "after_click.png");
+
+bgtk_destroy_mock(ctx);
